## 앱 계산안

- 총 직접 투입 인분 = 현장 공통 준비 인분(1회) + Σ[실제 부착면적 × 평판 기본 인분/m² + 독립적으로 위치를 맞춰 붙이는 시트 수 × 인분/장 + 이음·감아붙임 길이 × 인분/m + 코너·타공 등 상세작업 수 × 인분/개]. 여기서 인분은 작업자 1명의 투입 1분이다.
- 실제 붙이는 시트를 센다. 재단 배치 조각이 실제 시트와 1:1인지 확인하고 롤 수는 사용하지 않는다. 이음은 공유 경계 한 번, 감아붙임은 시공되는 변만 입력한다. 평판 계수에는 면을 따라 붙이는 시간, 장수 계수에는 시트별 정렬, 상세 계수에는 추가 작업시간만 넣는다. 몰딩처럼 길이가 작업량을 설명하는 부위에는 전개 폭 면적과 별도로 실제 프로파일 길이·코너의 추가 시간을 기록한다.
- 넓은 평면은 연속 부착 면적과 상대적으로 적은 정렬·마감 횟수가 반영된다. 롤 폭을 초과해 시트 정렬과 이음이 늘거나 2인 취급이 필요하면 실제 추가 투입을 더한다. 면적 구간 일괄 할인이나 자동 상한은 현장 기록으로 입증되기 전에는 도입하지 않는 편이 안전하다.
- 기초작업은 퍼티·샌딩·프라이머·기존 필름 제거를 별도 노무 항목에 입력하고 부자재와도 분리한다. 자연 건조 중 다른 작업이 가능하면 건조 경과시간 전체를 인건비에 더하지 않는다. 원단비는 배치에서 소요된 새 원단 길이 × 해당 매입 단가로 유지한다.
- 시공품수 = 인분 ÷ (1품 기준 작업시간 × 60). 부착 인건비 = 시공품수 × 품당 인건비. 기존 앱 예시 250,000원/품, 가정 8시간/품이면 약 521원/인분이다. 단독시공 0.5품 최소는 동일 부착 항목을 합산한 뒤 프로젝트에 1회 적용한다. 수동 계약 단가를 지정한 소그룹은 해당 단가를 적용한다.

## 비교 예시

평면 12인분/m², 시트 4인분/장, 추가 마감·이음 4인분/m, 상세작업 5인분/개로 가정했다. 전체시공의 부착만 비교하며 현장 공통 준비·기초작업은 비교에서 제외했다. 숫자는 시범 계산용이다.

| 같은 면적 10m² | 시트 | 추가 마감·이음 | 상세작업 | 투입 인분 | 인건비 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 넓은 평면 | 4장 | 8m | 0개 | 168 | 87,500원 |
| 분할 면·감아붙임이 많은 부위 | 12장 | 20m | 8개 | 288 | 150,000원 |
| 면적 단가 15,000원/m² 적용 | | | | | 150,000원 |

평면 계수를 10~14인분/m²로 가정하면 첫 줄의 인건비는 약 77,083~97,917원이다. 이는 단일 계수 민감도 예시로 예측 범위나 시장가가 아니다. 단독 작업이면 첫 줄은 이 가정에서 기존 0.5품 최소(125,000원)에 도달한다.

## 도입 검증

실측 전에는 작업량 기반 견적을 참고값으로 표시한다. 현장별 업체·작업자 수와 부착·준비·기초작업 실제 인분, 면적, 실제 시트, 이음·코너, 제외 범위와 재작업을 기록한다. 작업시간을 붙여 기록하지 않은 현장은 계수 산정용 자료에서 구분한다. 전체 작업을 현장 단위로 분리해 시간 기반 방식과 기존 면적 방식의 평균 절대오차 및 과다·과소 추정 방향을 비교한다. 넓은 평면과 몰딩·문틀 등 난도 높은 표본을 함께 포함하고, 같은 현장에서 잘라낸 조각을 학습과 검증에 나누지 않는다. 계수를 정한 뒤 후속 현장으로 검증해야 과거 건에만 들어맞는 조정을 줄일 수 있다.
