# 재단 여유치 설계 명세

## 1. 목적

조각의 입력 폭·길이와 실제 배치·견적에 사용하는 생산 치수를 분리한다.

- 입력 치수: 사용자가 입력한 원래 폭·길이
- 재단 여유치: 폭과 길이에 각각 한 번 더하는 공통 값
- 계산 치수: `입력 치수 + 재단 여유치`

예: 폭 100mm, 길이 200mm, 여유치 50mm이면 배치·견적 치수는 150×250mm이다.

## 2. 확정 동작

### 신규 입력

- 새로 생성되는 조각의 여유치 기본값은 50mm이다.
- 여유치는 0 이상의 정수만 허용한다.
- 여유치는 폭과 길이에 각각 동일하게 더한다.
- 수량에는 영향을 주지 않는다.

### 기존 프로젝트 호환

- 여유치 기능 도입 전에 저장되어 `cutAllowanceMm` 필드가 없는 프로젝트는 여유치 0mm로 복원한다.
- 여유치 기능 도입 후 저장되어 `cutAllowanceMm` 필드가 있는 프로젝트는 저장된 값을 그대로 복원한다.
- 저장값 0은 유효한 명시 값이므로 신규 기본값 50으로 바꾸지 않는다.
- 구형 프로젝트를 불러온 뒤 다시 저장하면 각 조각에 명시적인 여유치 0mm를 기록한다.

## 3. 데이터 모델과 경계

### 화면 입력 상태

`CuttingFormState`에 `cutAllowance: string`을 추가한다. 문자열을 유지해 모바일 숫자 입력 중 빈 값과 편집 상태를 안전하게 다룬다.

### 계산 경계

여유치 계산을 화면마다 중복하지 않고 전용 모듈에 모은다.

- `DEFAULT_CUT_ALLOWANCE_MM = 50`
- `LEGACY_CUT_ALLOWANCE_MM = 0`
- 입력값 정규화
- 입력 폭·길이와 여유치에서 계산 폭·길이 생성
- 여러 조각의 여유치 값이 동일한지 또는 혼합인지 요약

재단 배치 요청을 만드는 단일 경계에서 계산 치수를 적용한다. 재단계산 화면, 현재 입력 자동견적, 자투리 적합성 계산이 모두 같은 함수를 사용하도록 한다.

### 저장 형식

기존 계산 소비자의 호환성을 유지하기 위해 저장 작업의 `pieceWidthMm`, `pieceLengthMm`은 계산 치수로 유지한다. 원본 입력과 여유치를 아래 선택 필드로 함께 저장한다.

- `sourcePieceWidthMm?: number`
- `sourcePieceLengthMm?: number`
- `cutAllowanceMm?: number`

복원 규칙은 다음과 같다.

1. 세 필드가 있으면 원본 치수와 저장 여유치를 사용한다.
2. 여유치 필드가 없으면 구형 데이터로 간주하고 기존 `pieceWidthMm`, `pieceLengthMm`을 원본 치수로, 여유치를 0mm로 사용한다.
3. 일부 선택 필드만 있는 비정상 데이터는 계산 치수와 여유치의 관계가 음수가 되지 않도록 보수적으로 복원하고 0mm로 폴백한다.

## 4. 화면 설계

### 전체 일괄 설정

- 소그룹 입력 영역 상단에 `전체 여유치` 입력과 `전체 적용` 버튼을 둔다.
- 초기 표시값은 50mm이다.
- 전체 적용은 현재 화면의 모든 소그룹·모든 조각 값을 덮어쓴다.
- 적용 전 변경 대상 개수를 포함한 경고창을 표시하고 확인한 경우만 반영한다.
- 새 조각 기본값은 50mm로 유지하며, 전체 적용값이 이후 생성되는 조각의 영구 기본값을 바꾸지는 않는다.

### 소그룹 일괄 설정

- 각 소그룹 카드에 설정 버튼을 둔다.
- 설정 팝업에서 여유치를 입력하고 `소그룹 전체 적용`을 누르면 해당 소그룹 조각만 변경한다.
- 값이 모두 같으면 해당 값을, 서로 다르면 `혼합` 상태를 표시한다.
- 적용 전 변경 대상 조각 수를 보여주는 경고창을 표시한다.

### 조각별 설정

- 각 조각 행의 설정 버튼에서 조각별 여유치를 수정한다.
- 기존 한 줄 입력 레이아웃을 유지하기 위해 여유치 입력은 팝업으로 제공한다.
- 조각 행에는 현재 여유치를 짧게 확인할 수 있는 표시를 둔다.

### 표시 문구

- 조각 입력 영역 상단 단위 안내에 여유치 단위를 포함한다.
- 배치 미리보기와 내보내기 상세 정보에는 원본 치수, 여유치, 계산 치수를 구분해 표시한다.
- 좁은 조각 영역에서는 현재처럼 ID 중심으로 표시하고 상세 팝업에서 전체 정보를 제공한다.

## 5. 계산 적용 범위

아래 항목은 모두 계산 치수로 처리한다.

- 자동 배치와 대그룹별 분할 배치
- 회전 가능 여부와 회전 배치 치수
- 원본 롤 폭 적합성
- 자투리 필름 폭·길이 적합성
- 원단 사용 길이와 수율
- 견적의 원단 사용량
- 소그룹 난이도와 개소 수가 반영되는 시공 면적

원본 폭·길이는 편집, 저장, 상세 표시 목적으로 보존한다.

## 6. 오류 처리

- 음수, 숫자가 아닌 값, 무한값은 적용하지 않고 사용자에게 오류를 안내한다.
- 빈 입력은 편집 중에는 허용하지만 계산 또는 일괄 적용 시 유효성 검사를 한다.
- 계산 치수가 원본 롤 폭을 초과하면 기존 불가 조각 처리 경로를 그대로 사용한다.
- 일괄 적용을 취소하면 어떤 조각도 변경하지 않는다.

## 7. 테스트 전략

테스트 우선으로 아래 사례를 추가한다.

1. 신규 조각 기본 여유치 50mm
2. 100×200 + 50 => 150×250 계산
3. 전체·소그룹·조각별 적용 범위
4. 혼합 값 요약
5. 회전 시 계산 치수 사용
6. 자투리 적합성에 계산 치수 사용
7. 자동견적에 계산 치수와 실제 롤 길이 사용
8. 여유치 필드 없는 구형 프로젝트는 0mm 복원
9. 여유치 필드가 있는 이후 프로젝트는 0 포함 저장값 유지
10. 저장 후 다시 불러와 원본 치수·여유치·계산 결과 보존

## 8. 제외 범위

- 폭과 길이에 서로 다른 여유치
- 상·하·좌·우 비대칭 여유치
- 조각 수량 자동 변경
- 확인 없는 전체 덮어쓰기

## 9. 완료 조건

- 신규 조각은 50mm로 시작한다.
- 구형 프로젝트는 계산 결과가 바뀌지 않도록 0mm로 열린다.
- 이후 프로젝트는 저장된 여유치를 정확히 유지한다.
- 모든 배치·자투리·견적 경로가 동일한 계산 치수를 사용한다.
- 전체, 소그룹, 조각별 설정이 서로 지정된 범위만 변경한다.
- 기존 테스트와 신규 테스트가 모두 통과한다.
