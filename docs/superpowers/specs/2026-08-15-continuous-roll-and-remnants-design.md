# 연속 롤 최적화와 자투리 필름 관리 설계

- 확정일: 2026-08-15
- 대상: 필름 재단 계산기 2차 고도화
- 기본 목적: 필요한 제품 수량을 충족하면서 새 원단 사용 길이를 최소화한다.

## 1. 범위

이번 구현은 다음 기능을 포함한다.

1. 고정 장 계산 대신 고정 폭·연속 길이 롤 계산
2. 원단 절약 우선 자동배치
3. 제품 브랜드·번호 기반 규격 프리셋
4. 최근 계산 작업 저장·복원·삭제
5. 자투리 필름의 실제 폭·길이 저장과 재사용
6. CSV 결과 및 PDF 작업지시서 내보내기

계정 동기화, 서버 저장, 여러 제품 규격의 동시 네스팅, 자유형·L자 폴리곤 자투리는 이번 범위에서 제외한다.

## 2. 자동배치 모듈

외부 인터페이스는 `optimizeContinuousRollLayout(input)` 하나로 유지한다. 구현은 UI, 저장소, 파일 내보내기를 알지 못하는 결정적 순수 함수다.

### 2.1 입력

```ts
type ContinuousRollInput = {
  rollWidthMm: number;
  pieceWidthMm: number;
  pieceLengthMm: number;
  quantity: number;
  gapMm: number;
  sideMarginMm: number;
  startEndMarginMm: number;
  allowRotation: boolean;
  maxLengthMm?: number;
};
```

### 2.2 알고리즘

1. 좌우 여백을 제외한 가용 폭을 계산한다.
2. 가용 폭에 들어가는 기본·회전·혼합 행 패턴과 세로 구획 혼합 블록을 생성한다.
3. 각 후보에 생산량, 사용 높이, 회전 수, 재단 복잡도를 기록한다.
4. 필요 수량까지의 동적 계획표를 만들고 각 수량을 생산하는 최소 길이 후보 조합을 구한다.
5. 시작·끝 여백을 더해 실제 사용 길이와 좌표를 반환한다.

`maxLengthMm`이 지정되면 모든 후보와 최종 좌표가 해당 길이를 넘지 않도록 제한한다. 새 롤 계산은 길이 제한 없이 수행하고, 자투리 계산은 자투리의 실제 길이를 `maxLengthMm`으로 전달한다.

후보 우선순위는 다음과 같다.

```text
새 롤 사용 길이 최소
→ 초과 생산 최소
→ 폐기 면적 최소
→ 회전 제품 수 최소
→ 행 패턴 종류 최소
```

동일 입력은 항상 동일 결과를 반환한다. 입력 수량은 최대 100,000개로 제한한다.

### 2.2.1 실용형 최적화 계약 (2026-08-16 승인)

브라우저 안전성을 위해 계산 전 예상 상태·전이 수를 산정하고 다음 두 경로 중 하나를 결정적으로 선택한다.

- **완전 최적 경로:** 예상 작업량이 안전 예산 이하면 위 우선순위 전체를 정확하게 최적화한다.
- **원단 절약 경로:** 안전 예산을 넘으면 사용 길이를 가장 먼저 줄이는 제한된 후보 집합을 계산한다. 패턴 종류 수는 전역 최적화하지 않고 결과 정렬과 작업 편의용 보조 기준으로만 사용한다.

원단 절약 경로는 임의로 정확한 결과라고 표시하지 않는다. 물리적 길이 하한과 결과 길이가 같으면 `certified`, 그렇지 않으면 `approximate`를 반환하고 하한 대비 차이를 함께 표시한다. 유한 자투리에서는 계산된 후보 중 배치 수량을 최대화한 뒤 같은 기준을 적용한다. 어떤 경로에서도 실제 좌표, 수량, 자투리 길이 제한을 위반해서는 안 된다.

### 2.3 출력

```ts
type ContinuousRollResult = {
  placements: Placement[];
  usedLengthMm: number;
  producedQuantity: number;
  overproduction: number;
  utilizationPercent: number;
  wastePercent: number;
  normalCount: number;
  rotatedCount: number;
  rowPatterns: RowPatternUsage[];
  estimatedCutLines: number;
  optimizationStatus: 'exact' | 'certified' | 'approximate';
  lowerBoundLengthMm: number;
  optimalityGapMm: number;
  planningMetrics: {
    strategy: 'exact' | 'material-first';
    estimatedWork: number;
    retainedStates: number;
  };
};
```

## 3. 자투리 필름 관리

### 3.1 저장 모델

```ts
type FilmRemnant = {
  id: string;
  brand: string;
  productNumber: string;
  widthMm: number;
  lengthMm: number;
  quantity: number;
  createdAt: string;
  updatedAt: string;
  note?: string;
};
```

자투리는 재단 후 실제 남은 직사각형 크기 그대로 저장한다. 브랜드와 제품 번호의 조합은 원단 종류를 식별하며, 폭과 길이가 같아도 다른 브랜드·번호의 자투리는 합치지 않는다.

### 3.2 사용 가능성 판정

자동 계산은 선택한 브랜드·제품 번호와 일치하는 자투리 중 다음 조건을 만족하는 것만 후보로 사용한다.

- 좌우·상하 여백을 적용한 뒤 제품이 한 개 이상 들어감
- 회전 금지 시 기본 방향으로 제품이 들어감
- 폭이 원본 롤 폭보다 작아도 제품이 들어가면 사용 가능
- 배치의 사용 길이와 모든 좌표가 자투리의 실제 길이를 넘지 않음

여러 자투리를 사용할 수 있으며, 새 롤 절감 길이가 큰 후보를 우선한다. 절감 길이가 같으면 면적이 작은 자투리를 먼저 사용해 작은 재고부터 소진한다. 자투리로 충족하지 못한 수량만 새 연속 롤에서 계산한다.

### 3.3 재단 후 갱신

자투리에서 제품을 배치한 뒤 남은 영역은 겹치지 않는 최대 두 개의 직사각형으로 분리한다.

- 배치 오른쪽 잔여 직사각형
- 배치 아래쪽 잔여 직사각형

제품이 한 개도 들어가지 않는 잔여 영역은 저장하지 않는다. 사용 전 원본 자투리는 제거하고 유효한 잔여 직사각형을 같은 브랜드·제품 번호로 새로 저장한다. 사용자는 계산 결과를 확정하기 전까지 재고 변경을 적용하지 않는다.

## 4. 프리셋과 작업 이력

규격 프리셋은 브랜드, 제품 번호, 원단 폭, 제품 폭·길이, 기본 간격·여백을 저장한다. 브랜드와 제품 번호로 검색해 입력값을 채울 수 있다.

최근 작업은 계산 성공 시 자동 저장하며 최대 20개를 유지한다. 작업에는 입력, 선택된 자투리, 계산 결과 요약, 생성 시각을 저장한다. 작업을 불러오면 입력 조건을 복원하고 현재 자투리 재고를 기준으로 다시 계산한다. 과거 결과는 비교 정보로만 표시한다.

프리셋, 작업 이력, 자투리 재고는 버전이 있는 `AsyncStorage` 문서로 저장한다. 인증정보나 개인정보는 저장하지 않는다.

## 5. 사용자 화면

현재 반응형 2단 대시보드를 유지하고 다음을 추가한다.

- 상단 `원단 절약 우선` 모드 표시
- 브랜드·제품 번호 검색과 프리셋 선택·저장
- 자투리 사용 토글과 사용 가능한 자투리 목록
- 자투리별 생산 가능 수량과 예상 절감 길이
- 결과에서 자투리 사용량, 새 롤 사용 길이, 초과 생산량 표시
- 연속 롤 길이에 맞춘 스크롤 가능한 SVG 배치 도면
- 자투리 배치와 새 롤 배치를 탭으로 분리
- 계산 확정 시 자투리 재고 갱신
- 최근 작업 목록의 불러오기·이름 변경·삭제

결과를 계산하는 행위와 자투리 재고를 차감하는 행위는 분리한다. 사용자가 `작업 확정`을 눌러야 재고가 변경된다.

## 6. 내보내기

CSV에는 브랜드, 제품 번호, 입력 규격, 사용 자투리, 새 롤 필요 길이, 생산 수량, 초과 수량, 수율과 손실률을 기록한다.

PDF 작업지시서에는 제목, 생성 시각, 입력 조건, 자투리 사용 내역, 결과 요약, 배치 도면과 범례를 포함한다. 웹은 다운로드하고 모바일은 시스템 공유 화면을 사용한다. 내보내기 실패는 계산·재고 상태를 변경하지 않는다.

## 7. 오류 처리

다음 입력은 계산 전에 거부한다.

- 0, 음수, 숫자가 아닌 치수와 수량
- 음수 간격·여백
- 가용 폭에 제품이 한 개도 들어가지 않는 조건
- 100,000개를 초과하는 수량
- 폭이나 길이가 0 이하인 자투리
- 브랜드 또는 제품 번호가 없는 자투리

저장 데이터가 손상되면 유효한 항목만 복구하고 사용자에게 일부 항목을 불러오지 못했음을 알린다. 계산 결과가 생성된 뒤 자투리 재고가 바뀌면 확정 전에 다시 계산하도록 요구한다.

## 8. 검증 기준

- 연속 롤 결과는 동일 조건의 고정 장 계산보다 긴 새 원단을 요구하지 않는다.
- `폭 100`, 제품 `60×40`, 수량 `3`, 회전 허용 조건의 사용 길이는 80mm 이하이다.
- 모든 배치 좌표는 여백 내부에 있고 서로 겹치지 않는다.
- 회전 금지 결과에는 회전 배치가 없다.
- 마지막 행의 초과 생산과 새 롤 사용 길이가 후보 우선순위대로 선택된다.
- 원본 롤보다 폭이 작은 자투리도 제품이 들어가면 사용 후보가 된다.
- 사용할 수 없는 자투리는 재고에 남고 결과에 포함되지 않는다.
- 여러 자투리 사용 후 부족분만 새 롤에 배치된다.
- 작업 확정 전에는 자투리 재고가 변경되지 않는다.
- 자투리 갱신 후 생성되는 직사각형은 서로 겹치지 않는다.
- 프리셋과 최근 작업의 저장·복원·삭제가 동작한다.
- CSV 필드와 PDF 작업지시서 생성이 자동 테스트를 통과한다.
- TypeScript 검사, 전체 테스트, Expo 정적 웹 빌드가 통과한다.
