# 자동배치 우선순위

- 원단 절약을 소그룹 근접 배치보다 우선한다. 기존 크기순 배치 후보는 그대로 유지한다.
- 길이 제한이 있는 롤/자투리에서는 기존 생산 수량 우선 규칙을 유지하고, 동일 수량이면 사용 길이를 비교한다.
- 완성 수량과 사용 길이가 같은 후보끼리는 소그룹 조각 중심의 세로 분산을 우선 줄이고 가로 분산을 보조적으로 비교한다.
- 대그룹 ID와 소그룹 이름을 묶어 근접도 키를 생성한다. 소그룹 정보가 없는 요청은 기존 결정 규칙을 유지한다.
- 최대 500조각까지 소그룹순 후보를 추가 평가한다. 이보다 큰 요청도 기존 후보 간 근접도 비교는 적용한다.
- 휴리스틱 후보 탐색이며 전역 최적해나 모든 소그룹의 연속 배치를 보장하지 않는다.

## 도면 표시

- 동일 소그룹은 같은 색상을 사용한다. 색상은 현재 롤이나 목록 순서와 무관하다.
- 규격은 테두리 패턴으로 보조 구분한다. 회전해도 패턴은 유지한다.
- 제한된 색상/패턴은 반복될 수 있으므로 소그룹 범례와 정확한 조각 치수(mm)를 함께 표시한다.
- 선택 강조, 조각 ID, 완료 표시, 수동 이동/회전 규칙은 유지한다.
- 기존 저장 수동배치는 자동으로 덮어쓰지 않는다. 새 규칙은 새 자동계산 결과에 적용한다.

## 회귀 검증

`optimizeMergedRollLayout.test.ts`: 동일 사용 길이에서 소그룹 근접, 기존 후보보다 사용 길이가 늘어나지 않음, 수량/회전/비겹침 유지.

`planGroupedPieces.test.ts`: 실제 병합계획 경로로 소그룹 정보 전달.

`placementAppearance.test.ts`: 소그룹 색상 일관성, 회전 시 규격 패턴 유지.
