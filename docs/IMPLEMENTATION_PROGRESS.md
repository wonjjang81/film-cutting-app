# 고도화 구현 진행 상황

기준일: 2026-08-15

## 이번에 완료한 항목

- 공개 추적 `.env`와 클라이언트 GitHub 토큰 사용 제거
- 하드코딩 관리자 계정, 무조건 성공하는 회원 로그인, 공개 마스터 게스트 코드 제거
- 서버 인증이 없는 관리자 라우트를 탐색에서 숨기고 기능 비활성화
- 공개 `guest_codes.json`과 GitHub Contents API 직접 쓰기 제거
- `node_modules`, `.expo`, 로그, 환경 파일을 Git 추적 대상에서 제거
- 누락된 Expo Router 레이아웃과 계산 화면 복구
- 재단 계산을 `calculateFilmCut` 모듈로 분리하고 검증·회전·수율 계산 구현
- 계산 모듈 자동 테스트 6개 추가
- 웹 문서 언어, 제목, 설명, 테마 메타데이터 추가
- TypeScript 엄격 검사와 GitHub Actions 품질·Pages 배포 파이프라인 추가

## 검증 결과

- 계산 테스트: 6개 통과
- TypeScript: 오류 없음
- Expo 정적 웹 export: 성공, 9개 정적 라우트 생성
- 생성된 HTML: `lang=ko`, 제목, 설명 확인
- 작업 트리/빌드 결과의 기존 토큰·고정 인증값 검색: 검출 없음

## 외부에서 반드시 수행할 항목

1. GitHub 설정에서 과거에 노출된 개인 액세스 토큰을 즉시 폐기한다.
2. Git 이력에서 `.env`, `guest_codes.json`, 과거 인증 문자열, `node_modules`를 제거한다.
3. 이력 재작성 후 강제 푸시하고 기존 클론은 모두 폐기·재클론한다.
4. 실제 계정/관리 기능이 필요하면 서버와 DB를 선정한 뒤 서버 검증 세션으로 다시 구현한다.

클라이언트 정적 앱에는 비밀번호 검증, 관리자 권한 판정, 저장소 쓰기 토큰을 다시 넣지 않는다.

## UI/UX·자동배치 1차 고도화

- 920px 이상 2단, 모바일 1단 반응형 작업 화면
- 원단 규격·제품 규격·생산 조건 입력 그룹과 단위 표시
- 원단 간격·가장자리 여백 반영
- 기본 방향, 전체 회전, 세로 혼합, 가로 혼합 후보 자동 비교
- 배치 좌표와 회전 상태를 반환하는 독립 최적화 모듈
- SVG 기반 배치 번호·방향 색상·여백 미리보기
- 필요 원단, 장당 생산량, 총 사용 길이, 수율·손실률 결과 카드
- 혼합 배치·여백·간격·다중 원단·검증 조건을 포함해 전체 테스트 12개 통과
- TypeScript 검사 및 Expo 정적 웹 빌드 통과
