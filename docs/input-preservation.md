# 입력 보존

- 입력 변경 즉시 브라우저 로컬 임시저장. 서버 프로젝트 저장/재고 반영과 별개이다.
- 입력 화면이 마운트된 동안 60초마다 최신 입력의 별도 로컬 백업 1개를 갱신한다. 히스토리를 누적하지 않는다.
- 새로 열 때 임시입력을 먼저 복원한다. 임시입력이 손상되면 최근 분 단위 백업을 사용한다. 모두 손상되면 원본을 덮어쓰지 않고 오류를 표시한다.
- 사용자 및 프로젝트별로 분리한다. 새 프로젝트 열기는 명시적 새 입력 동작이며, 동일 화면의 새로고침은 초기화하지 않는다.
- ‘입력 초기화’는 의도적인 초기화로 취급하고 빈 입력을 다시 저장한다. 재계산 전 입력 복원이 가능하나 계산 결과 자체는 다시 계산해야 한다.
- 웹 F5/Ctrl+R/Cmd+R 차단 및 beforeunload 이탈 경고. 모바일 당겨서 새로고침을 줄이기 위한 overscroll 설정.
- 브라우저 도구모음/OS 재로딩은 완전 차단할 수 없다. 경고 표시와 백그라운드 타이머 주기는 브라우저 정책에 따라 달라질 수 있다.
- 브라우저 사이트 데이터 삭제/시크릿모드 종료/저장공간 정리는 로컬 입력도 삭제할 수 있다. 장기 보관은 프로젝트 저장/기존 JSON 내보내기를 사용한다.

검증: `node scripts/input-refresh-browser-check.cjs` (PLAYWRIGHT_MODULE 환경변수로 Playwright 경로 지정). 모든 API를 가로채므로 실제 프로젝트를 변경하지 않는다.
